## 🚀 Featured Projects

### 🏡 Rental Property Management System

A full-stack application for managing rental property listings and property visit bookings.

**Tech Stack:** Java · Spring Boot · Spring Security · JWT · Spring Data JPA · Hibernate · MySQL · React · Spring AI

**Key Features**
- Property listing creation, retrieval, updating, and deletion.
- Property search and filtering.
- REST API development and database integration.
- Separate backend services for authentication, property management, and booking.
- Service discovery using Netflix Eureka and centralized routing through an API Gateway.
- AI-powered conversational assistance using Spring AI and Google Gemini.

**My Contributions**
- Implemented the Property Management Service, including CRUD operations, search/filtering, and MySQL integration.
- Worked on the Spring AI feature using Spring Boot, ChatClient, and the Google Gemini API.

[Explore my GitHub repositories](https://github.com/KaustubhG-404?tab=repositories)
